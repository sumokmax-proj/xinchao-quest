# 완성 로드맵 (자율 개발용)

목표: `docs/game-design.md`의 **MVP 범위를 "하나의 완성된 게임"으로** 만든다 (2026-11-22 오너 결정, decisions-log #19).
완성된 게임 = 처음 켠 사람이 설명 없이 시작해서, 20~30분 동안 성장하며 놀고, 엔딩을 보고, 다음에 다시 켜도 진행이 남아 있는 게임.

Claude는 위에서부터 아직 끝나지 않은 마일스톤을 하나 골라 작업한다. 항목을 끝내면 `[x]`로 바꾸고, 마일스톤이 끝나면 태그를 붙인다.
항목은 Claude가 점검 결과에 따라 고치거나 추가해도 된다 (바꾼 이유는 `docs/dev-journal.md`에).

## 현재 위치 (2026-11-25, v0.11 = v1.0 후보)
- 완료: M1 학습 루프(v0.4) → M2 볼륨·게임성(v0.5) → M3 마을·스토리(v0.6) → M4 그래픽(v0.7) → M4.5 타격감(v0.8) → M5 마무리(v0.9) → 오늘의 목표·간격 복습(v0.10) → 스테이지 별·작은 화면(v0.11)
- 게임 구성: 마을 허브 ↔ 스테이지 6개(풀밭 → 요새) → 고블린 왕 → 엔딩. 몬스터 7종, 단어 89개, 상점(음식·장비), 마을 재건, 카툰 컷
- 자동 플레이(사람 수준 봇): 처음부터 엔딩까지 약 9분, 오류 0. 테스트 202개
- **남은 것: 오너 폰 확인 뒤 v1.0.** 그동안 자율 개발은 점검표에서 가장 낮은 항목을 계속 개선

## 오너 검수 대기 (자율 개발이 대신할 수 없는 것)
- 베트남어는 **하노이(북부) 표현만.** 남부 표현이나 북부·남부 비교는 넣지 않는다 (결정 #21)
- 베트남어 검수 방식 (결정 #22): **Claude가 1차 검수**, 자신 없는 것만 `"status": "check"` + `"note"` → 오너는 그것만 확인. 2026-11-25 기준 모든 단어·문장 1차 검수 완료, check 0개
- 나중에(외부 공개 전): 베트남 사람에게 전체 검수
- 폰 확인: v0.6(처음 시작·마을·상점·카툰 컷), v0.7(검사 모델·히트스톱·준비 동작), main(배경음·가로 화면·설정 창). 목록은 `docs/dev-journal.md`의 "오너에게"
- 스토리 톤(Lord Banh-mi-sh, 낙서풍 카툰), 배경음이 거슬리는지
- 점검표 점수는 Claude의 자체 채점이다. 손맛·재미·난이도는 오너가 폰으로 해 본 뒤에 확정한다

## M4.5 타격감 다듬기 (태그 v0.8) — 2026-11-24 오너 지시 — 완료 2026-11-25
참고: [타격감 켜 보기](https://game.bobthief.com/game-juice/play) (밥따뚜의 AI게임 유튜브). 같은 장면에 연출을 하나씩 켜고 끄며 비교하는 페이지.
**아이디어만 참고한다. 그 사이트의 코드·그림·소리는 가져오지 않는다** (사이트가 복제·추출을 금지함. 비슷한 것을 처음부터 만드는 건 허용).

이미 있는 것: 흰 번쩍, 넉백, 맞으면 찌그러짐, 히트스톱(0.045 / 크리 0.08 / 처치 0.1초), 타격 불꽃, 데미지 숫자, 처치 파편, 화면 흔들림.

- [x] **연출 스위치 (개발용):** 설정에서 연출을 하나씩 켜고 끄는 목록 + "전부 끄기 / 전부 켜기". 오너가 폰에서 직접 비교하며 어떤 연출이 손맛을 만드는지 판단하는 용도. 상태는 저장. 일반 플레이어에게는 안 보이게 (예: 버전 글자를 5번 누르면 열림)
- [x] **화면 흔들림은 센 공격에만:** 지금은 모든 타격에 흔들림. 크리티컬·처치·피격·보스 공격에만 남기고 일반 타격은 끄거나 아주 약하게 → 흔들림이 "센 한 방" 신호가 되게
- [x] **효과음 높낮이 변화:** 같은 효과음도 칠 때마다 높낮이를 조금씩 바꿔서 연속 공격이 덜 질리게 (예: ±5%)
- [x] **정답 마무리 일격 슬로 모션:** 퀴즈 정답 → 처치 순간 0.25배속으로 아주 잠깐. "말로 끝낸다"는 이 게임의 핵심 순간을 가장 크게 보여 주기
- [x] **쇼크웨이브:** 대장·고블린 왕 처치, 고블린 왕 내려찍기에 바닥으로 퍼지는 원 띠(또는 화면 일렁임). 성능을 보고 셰이더 대신 바닥 링 메시로도 가능
- [x] **진동 (지원 기기만):** 맞을 때·처치할 때 짧게 (`navigator.vibrate`, 안드로이드. 아이폰 사파리는 대부분 안 됨). 설정에서 끄기
- [x] 각 연출의 세기·시간은 `config.ts`의 `feel`에 모으고, 바꾸면 "이전 → 이후" 기록. 손맛 기준값(이동·쿨다운 등)은 바꾸지 않음
- [x] 자동 플레이 점검에서 히트스톱·슬로 모션이 퀴즈 제한시간·예고 시간을 잘못 줄이거나 늘리지 않는지 확인 (게임 시간 vs 연출 시간 구분 테스트)
