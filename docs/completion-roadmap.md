# 완성 로드맵 (자율 개발용)

목표: `docs/game-design.md`의 **MVP 범위를 "하나의 완성된 게임"으로** 만든다 (2026-11-22 오너 결정, decisions-log #19).
완성된 게임 = 처음 켠 사람이 설명 없이 시작해서, 20~30분 동안 성장하며 놀고, 엔딩을 보고, 다음에 다시 켜도 진행이 남아 있는 게임.

Claude는 위에서부터 아직 끝나지 않은 마일스톤을 하나 골라 작업한다. 항목을 끝내면 `[x]`로 바꾸고, 마일스톤이 끝나면 태그를 붙인다.
항목은 Claude가 점검 결과에 따라 고치거나 추가해도 된다 (바꾼 이유는 `docs/dev-journal.md`에).

## 현재 위치 (v0.3 기준)
- 맵 1개, 웨이브 3개(고블린 10마리 + 대장), 단어 28개, 한 판 약 40초 (자동 플레이 점검)
- 레벨·골드는 판이 끝나면 사라짐. 골드 쓸 곳 없음. 오답노트는 저장만 되고 볼 화면 없음

## M1. 학습 루프 완성 (태그 v0.4)
- [ ] 단어 50개 이상, 하노이(북부) 기준. 새 단어는 `"status": "draft"`로 표시 (오너 검수 전)
- [x] 진행 저장: 레벨·EXP·골드·처치 수·푼 문제 수가 판이 끝나도 남음
- [ ] 오답노트 화면: 틀린 단어 목록, 뜻, 발음 듣기
- [ ] 단어 도감: 처음 맞힌 단어 수집, 진행률 표시
- [x] 결과 화면에 이번 판에서 새로 배운 단어·다시 틀린 단어
- [ ] 문제 유형 다양화 최소 1개 (예: 성조만 다른 단어 구별)

## M2. 볼륨과 게임성 (태그 v0.5)
- [ ] 스테이지 구성: 같은 풀밭이라도 스테이지 5개 이상 (적 구성·배치·웨이브 수 다르게), 스테이지 선택 또는 순서대로 해금
- [ ] 적 변형 최소 2종 추가 (예: 느리지만 단단한 고블린, 빠르지만 약한 고블린, 원거리 예고). 예고 칸을 읽고 피하는 재미가 핵심
- [ ] 난이도 곡선: 자동 플레이 기준 1스테이지는 거의 안 맞고, 마지막 스테이지는 피격·사망이 실제로 일어남
- [ ] 골드 사용처 (보상은 학습 행동에만): 포션, 학습 보조 장비(힌트 1회, 제한시간 +2초 등). 과금 없음
- [ ] 지역 보스 1개: HP를 일정량 깎을 때마다 퀴즈, 마지막은 어려운 문제
- [ ] 엔딩: 보스를 이기면 엔딩 화면과 통계

## M3. 그래픽과 연출 (태그 v0.6)
- [ ] CC0 로폴리 에셋 적용 (검사, 고블린 종류별, 나무·바위·덤불·바닥). 출처는 `public/models/CREDITS.md`
- [ ] 애니메이션: 대기, 걷기, 공격, 피격, 빈사, 쓰러짐
- [ ] 타격감: 히트스톱, 파티클, 화면 흔들림 다듬기. 처치 연출
- [ ] 스테이지마다 분위기 차이 (시간대·조명·소품)
- [ ] 모바일 성능: 로딩 5초 이내, 중급 폰에서 끊김 없음. 에셋 용량 관리

## M4. 마무리 (태그 v1.0)
- [ ] 첫 5분 경험: 설명 없이 시작해서 이동·공격·피하기·퀴즈를 저절로 배우는지 (Show, don't tell)
- [ ] 사운드 다듬기 (효과음 종류, 배경음 선택)
- [ ] 모바일 조작 다듬기 (D-pad 크기, 스와이프, 가로 화면 처리)
- [ ] 설정: 소리, 도트 모드, 진행 초기화
- [ ] 자동 플레이 점검 여러 판에서 오류 0, 시간 초과 0
- [ ] 자체 점검표(`docs/self-review-rubric.md`) 모든 항목 3점 이상
