## 양식
```
## 사이클 N (YYYY-MM-DD HH:MM, 마일스톤 Mx)
- 한 일: (커밋 해시와 한 줄 요약)
- 점검: npm run playtest 결과 요약 (판 수, 결과, 시간, 맞은 횟수, 오류)
- 점수: 바뀐 항목만 "항목 이전→이후 (근거)"
- 바꾼 규칙·손맛 값: 없으면 "없음". 있으면 "이전 → 이후, 이유" (decisions-log에도)
- 오너 확인 필요: 베트남어 검수 대기 단어, 판단이 필요한 것
- 다음: 다음 사이클에 할 일 1~3개
```
