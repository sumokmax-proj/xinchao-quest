# 씬짜오 퀘스트 기획안 (베트남어 학습 3D 액션 RPG)

2026-11-22 · Kang Sumok (Max)

## 게임 개요

실시간으로 고블린을 베다가, 마지막 일격은 베트남어 2지선다 퀴즈로 끝내는 3D 탑뷰 액션 RPG. 싸움은 손으로 하고 마무리는 머리로 하는 구조다.

- **가제:** 씬짜오 퀘스트 (Xin Chào Quest)
- **장르:** 3D 탑뷰 실시간 그리드 액션 RPG. 이스처럼 적에게 부딪히면 자동으로 공격하는 범프 공격 방식
- **주인공:** 검을 든 모험가. 타일 단위로 상하좌우 4방향 이동
- **화면·조작:** 세로 화면, 한 손 조작. 하단의 큰 4방향 버튼(D-pad)과 스와이프, PC는 방향키
- **1차 타깃:** 베트남에 살면서 실생활 베트남어가 필요한 한국인 성인 학습자 (OPIc IM 수준 목표)
- **플랫폼:** 모바일 웹 우선, PC 웹 지원
- **핵심 가치:** 조작이 단순해 바로 손에 붙고, 문제는 적을 쓰러뜨리는 순간에만 나와 흐름을 끊지 않음

| Rumble Heroes (PLAYHARD) | 세로 화면 한 손 조작, 이동만으로 싸우는 단순함, 귀여운 2등신 캐릭터, 마을 허브와 캠프 | 에너지·과금 중심의 반복 사냥 |

두 게임 모두 2D지만 같은 인상을 3D 탑뷰로 만든다. 자세한 조사는 `reference-games-research.md`.

## 핵심 게임 루프

1. 필드에서 고블린과 조우
2. 범프 공격으로 HP를 깎음 (빨간 예고 칸은 피함)
3. HP 0 → 빈사 퀴즈
   - 정답 → 처치, EXP·골드 → 계속 사냥 또는 레벨업·장비
   - 오답 → 적 HP 일부 회복 + 오답노트 → 다시 싸움
4. 준비되면 지역 보스 도전 → 보스 처치 → 다음 지역 해금 → 새 필드

전체 구성(마을 허브 ↔ 필드, 마을 재건, 스토리)은 아래 "게임 구성" 참고.

싸움은 실시간 범프 공격으로 하고, 마지막 일격만 퀴즈다. 틀리면 적이 회복해 다시 싸워야 하므로 오답이 곧 손해가 되고, 그 단어는 오답노트로 다시 나온다.

## 게임 구성: 마을 ↔ 필드 (2026-11-24 개정, Rumble Heroes 참고)

Rumble Heroes의 "마을(허브)에서 준비 → 필드에 나가 싸움 → 돌아와 마을을 키움" 구조를 가져온다. 다만 자원 채집·그라인드·과금 대신 **마을을 키우는 재료가 "배운 단어"** 다. 공부한 만큼 마을이 살아난다.

### 한 바퀴
1. **마을** (걸어다니는 3D 허브, 전투 없음): NPC와 이야기, 상점에서 준비, 단어장 확인
2. **마을 출구(성문)** 로 걸어가면 → 갈 곳 목록 (열린 스테이지)
3. **필드 스테이지**: 웨이브 전투 + 빈사 퀴즈 (지금까지의 핵심 루프 그대로)
4. 클리어 → 짧은 카툰 컷(가끔) → **마을로 귀환**, 보상 정산, 새로 열린 것 확인
5. 마지막 요새의 고블린 왕을 물리치면 엔딩

### 마을의 조작: 범프 = 대화
필드와 똑같이 그리드 4방향 이동이다. 적에게 부딪히면 공격이듯, **NPC에게 부딪히면 말을 건다.** 새 조작을 배울 필요가 없다 (Show, don't tell).

| 장소 (NPC) | 하는 일 |
| --- | --- |
| 성 — Lord Banh-mi-sh | 스토리 진행, 다음 지역 안내 |
| 반미 가게 (음식 상인) | 음식 소모품: bánh mì, phở bò, bún chả, cà phê trứng |
| 대장간 | 장비: 검·갑옷 강화, 모래시계, 행운 부적 |
| 서당 (훈장님) | 단어장: 도감·오답노트, 발음 듣기 |
| 마을 사람들 | 베트남 사람이 외국인에게 자주 묻는 질문을 진지하게 묻는다 ("Ăn cơm chưa?"). 2지선다로 대답 → 맞히면 작은 보상 |
| 성문 | 필드로 나가기 (스테이지 목록) |

### 마을 재건 (Rumble Heroes의 마을 키우기)
처음 마을은 고블린 때문에 망가져 있다. **단어 도감을 모을수록** 건물이 하나씩 복구되고 NPC가 돌아온다.
- 예: 도감 0개 → 성·반미 가게만 / 10개 → 대장간 / 20개 → 서당 / 35개 → 카페 / 50개 → 분수 광장 / 70개 → 마을 축제
- 숫자는 `src/data/village.json`에서 조정. 스테이지 클리어가 아니라 **배운 단어 수**가 기준이라, 공부가 곧 마을의 성장으로 보인다

### 스토리 (docs/story-concept.md 반영, 2026-11-24 오너 허락)
- **시작은 설명 없이 바로 풀밭 전투.** 첫 웨이브를 잡은 순간 4컷 회상: 퇴근길 → 이세계 버스 → 눈을 뜨니 검 → Lord Banh-mi-sh의 부탁 ("이 세계에서는 마물의 마지막 숨을 *말*로 끊어야 하오")
- 카툰 컷: 3~4컷, 컷마다 대사 한 줄, 탭하면 넘어가고 건너뛰기 가능. 그림은 게임 안에서 그린 낙서풍 SVG (외부 그림 없음)
- 1스테이지 클리어 → 처음 마을 도착 컷. 이후 지역 도착·보스 등장·엔딩에 짧은 컷
- 톤: 겉은 진지한 중세 판타지, 속은 살짝 병맛. 피식 하고 바로 플레이로
- 엔딩: 고블린 왕을 물리치고 원래 세계(하노이 퇴근길)로 돌아와, 처음으로 베트남어로 막힘없이 주문한다
- 호안끼엠 전설(신검·Kim Quy)은 존중이 필요해서 **이번에는 넣지 않는다** (오너와 표현을 정한 뒤)

### 음식 아이템 = 단어
상점 이름과 아이템은 베트남어로 보여 주고, **처음 산 음식은 단어 도감에 들어간다** (주제 "음식").

| 아이템 | 효과 |
| --- | --- |
| bánh mì (반미) | HP 30% 회복. 싸고 흔함 |
| phở bò (소고기 쌀국수) | HP 70% 회복 |
| bún chả (분짜) | HP 40% 회복 + 그 판 동안 공격력 +20% (한 번) |
| cà phê trứng (에그커피) | 다음 퀴즈 3개 제한시간 +2초 |

장비(대장간): 강철 검·황금 검(공격력), 가죽·철 갑옷(받는 피해 감소), 모래시계(퀴즈 +2초, 상시), 행운 부적(판마다 한 번 틀려도 적이 회복 안 함).
골드는 퀴즈를 맞혀 처치할 때만 들어오므로 사는 것도 학습 보상이다 (결정 #15 유지, 과금 없음).

### 필드 스테이지 (6개, 지역마다 다른 몬스터와 단어 주제)
| # | 스테이지 | 단어 주제 | 새 몬스터 (예고 모양) |
| --- | --- | --- | --- |
| 1 | 마을 앞 풀밭 | 인사·자기소개 | 고블린 (1칸), 대장 고블린 |
| 2 | 대나무 숲길 | 가족·일상 | 원숭이 (빠름, 짧은 예고) |
| 3 | 홍강 둑길 | 숫자·카페 | 물소 (앞 2칸 돌진) |
| 4 | 시장 골목 | 시장 | 들개 (가로 3칸) |
| 5 | 논두렁 길 | 길·시간 | 개구리 (멀리서 일직선 물총) |
| 6 | 고블린 요새 | 모든 단어 | 고블린 왕 (지역 보스: HP 2/3·1/3마다 퀴즈, 마지막은 성조 문제) |

### 하지 않는 것 (Rumble Heroes에서 버리는 것)
- 자원 채집·건설 대기 시간·에너지·과금
- 영웅 여럿을 모으는 파티 (한 명의 검사에 집중. 나중에 "어린 거북 정령 동료" 같은 1명 동료는 검토)

## 로그라이트 요소 (2026-11-28 추가, 결정 #27)

로그라이크 영상(무작위성·빌드·플레이어 성장)을 참고해, **영구 죽음과 턴제는 빼고 로그라이트**로 간다. 같은 스테이지를 다시 해도 판마다 다르게 느껴지게 해서, 별 ★★★를 노리고 다시 도전할 이유를 만든다.

| 층 | 내용 |
| --- | --- |
| 판이 끝나도 남는 것 (이미 있음) | 레벨, 골드, 장비, 단어 도감, 마을 재건. 쓰러져도 남는다 |
| 그 판에서만 바뀌는 것 (이번에 추가) | 웨이브 구성, 판 보너스, 황금 고블린 |

1. **웨이브 구성 섞기** (`src/core/WaveRoll.ts`): 대장·보스와 웨이브에 있던 몬스터 종류 한 마리씩은 그대로 두고, 나머지는 같은 "강함 점수"만큼 그 스테이지 몬스터 중에서 무작위로 채운다. 난이도는 비슷하고 조합만 바뀐다. 1스테이지(고블린만)는 그대로. 점수는 `config.ts`의 `run.enemyCost`
2. **판 보너스 줍기** (`src/core/RunBonus.ts`, `src/data/bonuses.json`): 웨이브를 깨면(마지막 제외) 바닥에 빛나는 물건 2개가 떨어진다. **걸어가서 밟으면 줍고**, 나머지는 사라지고 다음 웨이브가 온다. 효과는 그 판에서만. 물건 8종: 공격·크리티컬·피해 감소·회복·골드 / 학습 보조(퀴즈 +1.5초·오답 1번 보호·복습 두루마리). 그 판에 퀴즈를 25% 이상 틀렸으면 학습 보조 물건이 꼭 하나 나온다. 처음 한 번만 "하나를 골라 주우세요" 한 줄
3. **황금 고블린** (`CONFIG.enemies.golden`): 판마다 30% 확률로 한 웨이브에 나타나 도망 다닌다. 공격하지 않고, 12초 안에 잡아 퀴즈를 맞히면 골드를 많이 준다. 놓쳐도 손해 없음. 웨이브 진행에는 세지 않는다

- 2·3은 **1스테이지를 처음 깬 뒤부터** 나온다 (첫 판은 전투만 배운다)
- 하지 않는 것: 영구 죽음, 턴제, 판 보너스를 다음 판으로 가져가기, 맵 장애물 무작위 생성, 돈으로 사는 보너스

## 전투 시스템

맵은 타일 격자이고, 고블린이 있는 칸으로 이동하려 하면 그것이 공격이다. HP가 0이 된 고블린은 빈사 상태가 되어 머리 위에 2지선다 퀴즈를 띄우고, 정답이면 처치, 오답이면 HP를 조금 회복한다.

1. **이동:** 타일 단위로 상하좌우 이동. 버튼을 누르고 있으면 계속 걸음
2. **범프 공격:** 고블린 칸 쪽으로 이동하면 제자리에서 검을 휘둘러 데미지. 계속 누르고 있으면 일정 간격으로 연속 공격
3. **적의 예고:** 고블린은 공격 전 자기 공격 칸을 바닥에 빨간색으로 잠깐 표시. 그 칸에서 빠지면 피할 수 있음
4. **빈사:** HP가 0이 된 고블린은 비틀거리며 멈추고, 머리 위에 문제와 왼쪽·오른쪽 답이 뜸
5. **마무리 퀴즈:** 제한시간(5초) 안에 D-pad ← 또는 →로 답을 고름. 이동 버튼이 그대로 답 버튼
6. **결과:** 정답이면 고블린이 쓰러지고 EXP·골드. 오답이나 시간 초과면 최대 HP의 15%를 회복하고 다시 움직이며, 그 단어는 오답노트에 들어감

| 조작 | 평소 | 빈사 퀴즈 중 |
| --- | --- | --- |
| ← / → (D-pad, 방향키) | 좌우 이동, 범프 공격 | 왼쪽 답 / 오른쪽 답 |
| ↑ / ↓ | 상하 이동, 범프 공격 | 사용 안 함 |
| 스와이프 (모바일) | 한 칸 이동 | 좌·우 스와이프로 답 선택 |

문제는 머리 위에서 한눈에 읽혀야 하므로 짧게 만든다. 단어 뜻, 한국어→베트남어, 성조 구별이 기본이고, 오답 보기는 헷갈리기 쉬운 단어로 고른다.

적은 세 등급이다. 일반 고블린은 마무리 1문제, 대장 고블린은 2문제 연속, 지역 보스는 HP를 일정량 깎을 때마다 퀴즈가 나오고 마지막은 빈칸 채우기 같은 어려운 문제로 끝낸다.

## 보상과 성장

보상은 학습 행동에만 붙는다. 돈을 내고 강해지는 구조는 넣지 않아서, 레벨이 곧 실력이 되도록 한다.

| 보상 | 얻는 방법 | 쓰임 |
| --- | --- | --- |
| 경험치(EXP) | 정답, 몬스터 처치 | 레벨업 → HP·공격력 상승 |
| 골드(đồng) | 처치, 일일 퀘스트 | 상점에서 포션·장비 구매 |
| 장비 | 보스 드롭, 상점 | 힌트 1회, 제한시간 +3초 같은 학습 보조 효과 |
| 단어 도감 | 새 단어를 처음 맞힐 때 | 수집 욕구, 복습 목록 |
| 스테이지 별 | 클리어 ★, 퀴즈 정답률 80% ★★, 95% ★★★ | 단어를 더 잘 외워 다시 도전 (표시만) |
| 지역 해금 | 지역 보스 처치 | 다음 스테이지 진입 |
| 연속 출석 보상 | 매일 일일 퀘스트 완료 | 7일·30일 달성 시 칭호·희귀 장비 |

게임 속 화폐를 베트남 동(đồng)으로 하면 가격 숫자를 읽는 연습까지 자연스럽게 연결된다.

## 학습 설계

스테이지는 하노이 실생활 장면으로 구성하고, 틀린 문제는 간격을 두고 다시 나오게 한다. OPIc IM에 자주 나오는 자기소개·일상·장소 묘사 주제를 앞쪽에 배치한다.

1. 우리 집 — 인사, 자기소개, 가족
2. 골목 카페 — 주문, 숫자, 맛 표현
3. 시장 — 가격 묻기, 흥정, 물건 이름
4. 그랩 오토바이 — 장소, 방향, 시간
5. 회사 — 일정, 회의, 요청·거절
6. 병원·은행 — 증상 말하기, 서류 업무

- **오답 부활:** 틀린 단어는 '부활 몬스터'가 되어 1일·3일·7일 뒤 사냥터에 다시 나타난다. 연속으로 맞히면 오답노트에서 빠진다. (구현: 부활한 단어는 퀴즈에서 먼저 나오고 말풍선에 "부활한 단어!" 표시, 맞히면 보너스 골드. 별도 부활 몬스터 모델은 아직)
- **동기부여:** 일일 퀘스트(10문제), 연속 출석, 주간 보스. 하루 목표를 작게 잡아 끊기지 않게 하는 것이 핵심이다. (구현: 오늘의 목표 = 정답 10개 → 골드, 연속 출석 보너스. 주간 보스는 아직)
- **발음·표현 기준:** 하노이(북부)만. 남부 표현이나 북부·남부 비교는 다루지 않는다
- **문제 데이터:** 문항마다 단어, 뜻, 음성, 예문, 난이도, 주제를 갖는 JSON 문제 은행으로 관리해 코드 수정 없이 문제를 늘린다.
- **음성:** 처음에는 브라우저 내장 베트남어 TTS, 품질이 아쉬우면 원어민 녹음으로 교체

## 3D 탑뷰 연출

Rumble Heroes·Guidus의 탑뷰 인상을 3D로 만든다. 원근감 없는 직교 카메라로 위에서 내려다보고, 타일 맵과 귀여운 로폴리 캐릭터를 쓴다.

| 항목 | 결정 |
| --- | --- |
| 화면 | 세로 화면(폰 기준), PC는 세로 비율 창으로 표시 |
| 카메라 | 직교(Orthographic) 카메라, 약 60~70도로 내려다봄, 회전 없이 플레이어를 부드럽게 따라감 |
| 맵 | 1×1 타일 격자. 바닥·벽·문·횃불을 조각으로 조립하는 모듈식 |
| 캐릭터 | 머리가 큰 2~2.5등신 로폴리. 검사는 밝은 색, 고블린은 초록 계열로 배경과 구분 |
| 도트 느낌(선택) | 저해상도로 그린 뒤 확대하는 픽셀화 후처리. 켜면 Guidus처럼 도트 질감, 끄면 깔끔한 로폴리 |
| 조명 | 어두운 환경광 + 횃불 점광원. 던전은 어둡게, 마을은 밝게 |
| 퀴즈 표시 | 화면 위 라벨(HTML)로 고블린 머리 위에 붙여 글자가 항상 선명하게 보이게 함 |
| 타격감 | 히트 때 하얗게 번쩍임, 밀려남·찌그러짐, 히트스톱, 불꽃, 데미지 숫자. 화면 흔들림은 크리티컬·처치·피격·보스 공격 같은 센 공격에만. 효과음은 칠 때마다 높낮이 ±5%. 대장·왕 처치와 왕의 내려찍기는 바닥 쇼크웨이브. 지원 기기는 맞을 때·처치할 때 짧은 진동 |
| 마무리 연출 | 빈사 때 주변이 어두워지고 시간이 느려짐. 정답으로 처치하는 순간 0.25배속 슬로 모션 + 살짝 확대. 연출은 퀴즈 제한시간과 플레이어 조작을 늦추지 않음 |
| 에셋 | KayKit(캐릭터·던전), Kenney, Quaternius 같은 CC0 로폴리 팩 |

Guidus 리뷰에서도 발열이 단점으로 꼽혔으므로 그림자와 광원 수를 제한한다. 저해상도 렌더링은 도트 느낌과 성능을 동시에 잡는 수단이기도 하다.

## MVP 범위와 기술 스택

MVP는 "부딪혀서 베고, 퀴즈로 끝내는 흐름이 손맛이 있는가"만 검증한다. (2026-11-22 프로토타입으로 검증 완료: 재밌음)

- **포함:** 타일 맵 1개(마을 앞 풀밭), 검사 1명, 일반 고블린 1종 + 대장 1, 4방향 그리드 이동과 D-pad, 범프 공격, 공격 칸 예고, 빈사 퀴즈(2지선다), 오답 시 HP 회복, 단어 50개, EXP·레벨·골드, 오답노트, 기기 내 저장
- **나중에:** 추가 지역, 장비 상점, 듣기 문제, 로그인, 수익화

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 3D 엔진 | Three.js + TypeScript | 웹에서 바로 실행, 무료, 자료가 많음 |
| 빌드 | Vite | 설정이 가볍고 저장하면 바로 반영 |
| 충돌 처리 | 타일 점유 체크 직접 구현 | 탑뷰 그리드라 물리 엔진 없이 충분 |
| 퀴즈 UI | HTML 오버레이 | 한글·베트남어 글자가 선명하고 만들기 쉬움 |
| 문제 데이터 | JSON 파일 | 코드 수정 없이 문제 추가 |
| 저장 | localStorage → Supabase | 무료로 시작, 나중에 기기 간 동기화 |
| 배포 | GitHub Pages | 무료, main merge 시 자동 배포 |
| 개발 도구 | Claude Code (웹 우선, 나중에 로컬 CLI 병행) | 파일이 많아 프로젝트 단위 관리가 필요 |

나중에 앱스토어 출시까지 생각한다면 Godot 4도 후보다. 다만 웹 프로토타입을 빨리 돌리기에는 Three.js가 유리하다.
