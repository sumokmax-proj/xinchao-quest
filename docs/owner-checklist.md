# 오너 확인 목록

**상태: 확인 대기 중** (2026-11-26 작성, 확인할 버전 `v0.15`)

- 확인할 곳 (폰): https://sumokmax-proj.github.io/xinchao-quest/
- `v0.13` 태그는 빌드가 깨진 버전이라 쓰지 않습니다.
- 결과는 편하게 말로 알려 주면 됩니다. 예: "스와이프는 좋은데 흔들림이 약해. 3스테이지가 너무 쉬워." 문제가 있는 화면은 스크린샷이 있으면 좋습니다.
- Claude는 답을 받으면 여기에 체크하고 결과를 한 줄 적습니다.

## 1. 짧게 확인 (10분 정도)
- [ ] **조작:** 방향 버튼(D-pad)을 누른 채 미끄러뜨리기, 화면 스와이프로 걷기가 편한가?
- [ ] **퀴즈 입력:** 걷던 중 퀴즈가 떠도 답이 실수로 눌리지 않는가?
- [ ] **타격감:** 때리고 처치할 때 시원한가? 거슬리는 연출이 있는가? (설정 맨 아래 **버전 글자를 5번** 누르면 연출 스위치가 열림. 전부 끄기와 전부 켜기를 비교)
- [ ] **화면:** 몬스터가 서로 구별되는가? 글자가 겹치거나 잘리는 곳이 있는가? D-pad에 가려 답답하지 않은가?
- [ ] **기기:** 끊김, 발열, 소리, 진동(지원하는 폰만)은 괜찮은가?
- [ ] **배경음:** 거슬리지 않는가?

## 2. 여유 있을 때
- [ ] **플레이 시간:** 처음부터 엔딩까지 해 보고 엔딩 화면의 **"총 플레이 시간"** 알려 주기. 점검표에서 가장 낮은 항목(3점)이라 필요합니다.
  - ⚠️ 처음부터 하려고 설정에서 진행을 초기화하면 **기존 진행이 지워집니다.**
- [ ] **난이도:** 너무 쉽거나 어려운 스테이지가 있는가?
- [ ] **처음 흐름과 이야기:** 첫 시작, 마을, 상점, 카툰 컷, 이야기 말투(Lord Banh-mi-sh, 낙서풍 그림)가 괜찮은가?
