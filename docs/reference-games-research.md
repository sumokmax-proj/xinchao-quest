## 2. Rumble Heroes : Adventure RPG

### 핵심
- 납치된 공주를 구하러 영웅 파티를 이끄는 캐주얼 RPG. 시작은 마을 재건(나무·광석·고기 채집, 건물 건설)이고 펍에서 영웅을 모집한다.
- 가장 큰 특징은 **한 손 조작**이다. 화면 아무 곳이나 눌러 끌면 가상 조이스틱이 생기고, 파티 전체가 함께 움직인다. 세로 화면에 맞춰져 있다.
- **자동 전투:** 영웅들이 가까운 몬스터를 자동으로 노려 공격한다. 리뷰에 따르면 이동 중에는 공격하지 않고 멈춰야 공격해서, "언제 멈추고 언제 빠질지"가 유일한 전술이다.
- 자원도 사거리 안에 있으면 자동으로 채집한다.
- 필드 어디에나 캠프를 세울 수 있고, 던전에서는 수백 마리 몬스터가 한꺼번에 몰려온다.

### 평가 포인트
- 장점: 쉽고 재미있는 한 손 플레이, 귀여운 그래픽, 공격·사망 애니메이션이 매끄러움
- 단점: 전투 깊이가 얕음. 과금하지 않으면 반복 사냥(그라인드) 부담이 크다는 평가

### 우리 게임에 가져올 것
- 세로 화면 + 한 손 조작
- "멈추면 자동 공격"처럼 **조작은 이동 하나로 단순하게**
- 마을(허브) + 필드 + 던전 구조, 캠프 개념
- 반면교사: 그라인드·과금 압박은 학습 게임에서 동기를 오히려 깎으므로 피함

## 3. Guidus 시리즈 (izzle)

### Guidus (모바일, Pixel Roguelike RPG)
- 왕궁 아래 봉인됐던 심연의 몬스터가 깨어나 왕궁을 되찾는 픽셀 로그라이크.
- 함정, 보물, 런마다 다른 영웅·축복 조합. 영구 성장이 있어 로그라이트에 가깝다는 평가
- 리뷰 키워드: 반응성 좋은 조작, 매력적인 도트 그래픽, 과금 압박이 적음. 단점으로 발열·최적화, 후반 난이도 스파이크

### Guidus Zero (PC/Xbox)
- 2025년 3월 Steam, 2025년 9월 Xbox 출시. 가격 $14.99
- **실시간 그리드 기반 액션 로그라이크.** 4방향으로 칸을 이동하며, 적의 위치와 공격 범위를 주의 깊게 봐야 한다.
- 개발진은 "능력치 성장보다 전투마다 쌓이는 판단력과 감각이 진짜 성장"이라고 설명
- 리뷰: 집중력과 계획이 필요한 게임. 아무렇게나 클릭하는 플레이와는 맞지 않음

### Guidus One (데모 공개)
- Guidus 세계관의 다음 작품. "모든 칸이 중요한" 실시간 그리드 로그라이크로 소개되며 탐험·전투 핵심 시스템을 담은 데모가 공개됨
- 첨부 스크린샷에서 보이는 요소: 세로 화면, 거의 위에서 내려다보는 시점, 타일 바닥의 던전, 횃불 조명, 화면 하단의 큰 4방향 버튼(D-pad), 목표 안내 문구("여신상에게 축복 받기"), 캠프 버튼

### 우리 게임에 가져올 것
- **타일(그리드) 단위 4방향 이동.** 기획안의 "상하좌우 이동"과 "부딪히면 공격(범프)"이 그리드에서 가장 깔끔하게 맞아떨어진다. 적이 있는 칸으로 이동하려 하면 = 공격
- 적의 공격 범위를 바닥 칸에 미리 빨갛게 표시(텔레그래프) → 피하고 때리는 리듬
- 큰 D-pad 버튼, 화면 상단의 짧은 목표 문구
- 어두운 바닥 + 따뜻한 횃불 조명의 분위기

## 4. 이 느낌을 3D 탑뷰로 구현하는 방법

레퍼런스 두 게임은 모두 2D지만, 같은 인상을 3D로 낼 수 있다.

| 요소 | 구현 방식 |
| --- | --- |
| 카메라 | 원근감이 없는 **직교(Orthographic) 카메라**, 위에서 약 60~70도로 내려다봄. 회전 없음 |
| 맵 | 1×1 크기 타일을 격자로 배치하는 모듈식 맵. 바닥·벽·문·횃불을 조각으로 조립 |
| 캐릭터 | 머리가 큰 2~2.5등신 로폴리(또는 복셀) 모델. 귀여운 비율이 Rumble Heroes 느낌을 냄 |
| 도트 느낌 | 화면을 저해상도(예: 가로 320px)로 그린 뒤 확대하는 **픽셀화 후처리**. 3D인데도 Guidus 같은 도트 질감 |
| 조명 | 어두운 환경광 + 횃불 위치의 점광원. 플레이어 주변만 밝게 |
| 연출 | 히트 시 하얀 번쩍임, 밀려남, 카메라 흔들림. 빈사 시 주변이 어두워지고 시간이 느려짐 |
| 에셋 | KayKit(캐릭터·던전 팩), Kenney, Quaternius 등 CC0 로폴리 팩. 복셀로 가면 MagicaVoxel로 직접 제작 가능 |

장점: 같은 모델로 회전·조명·그림자를 공짜로 얻고, 2D처럼 방향별 스프라이트를 따로 그릴 필요가 없다.
주의: 모바일 발열(Guidus 리뷰에서도 지적). 그림자와 광원 수를 제한하고, 저해상도 렌더링 자체가 성능에도 유리하다.

## 5. 기획안에 반영한 결정

1. 이동은 **타일 단위 4방향 그리드**로 한다 (Guidus).
2. 적이 있는 칸으로 이동하면 공격하는 **범프 공격**을 그리드 위에서 구현한다 (이스 + Guidus).
3. **세로 화면, 한 손 조작**. 하단에 큰 D-pad (Guidus) / 스와이프도 지원 (Rumble Heroes).
4. 빈사 퀴즈의 2지선다는 **D-pad 왼쪽·오른쪽 버튼이 그대로 답 버튼**이 된다. 조작을 새로 배울 필요가 없다.
5. 적의 다음 공격 칸을 바닥에 미리 표시해 피하는 재미를 준다.
6. 그래픽은 **직교 카메라 3D 탑뷰 + 로폴리 2.5등신 + 선택적 픽셀화 후처리**.
7. 마을(허브)에서 상점·오답노트·캠프를 쓰는 구조는 Rumble Heroes를 참고하되, 그라인드·과금 압박은 넣지 않는다.
