# 자체 점검표

매 사이클 끝에 Claude가 스스로 채점한다. 각 항목 1~5점, 근거를 한 줄로.
근거는 반드시 실제로 확인한 것: `npm run playtest` 리포트, 스크린샷, 코드, 테스트 결과. "아마 괜찮을 것" 금지.
점수와 근거는 `docs/dev-journal.md`의 해당 사이클에 표로 남긴다. 다음 사이클은 **가장 낮은 항목**부터 고친다.

## 자동 플레이 점검 돌리는 법
```bash
npm run playtest -- --runs 3
```
- `--wrong-rate 0.2` 퀴즈 오답 비율, `--dodge 0.7` 예고 피하는 확률 (사람 수준). `--dodge 0.3`이면 서툰 사람
- 결과: `playtest-output/<날짜시간>/report.md`와 스크린샷 (git에는 안 올라감)
- 스크린샷은 직접 열어서 본다 (그래픽·UI 채점의 근거)
- 게임 상태는 `Game.debugSnapshot()` 형식으로 읽는다. 기능을 추가하면 이 형식과 봇(`scripts/playtest.mjs`)도 함께 고친다

## 채점 기준

| 영역 | 항목 | 1점 | 3점 | 5점 |
| --- | --- | --- | --- | --- |
| 볼륨 | 한 판·전체 플레이 시간 | 1분 미만, 엔딩 없음 | 10분 이상, 진행이 저장됨 | 20~30분, 엔딩까지 다시 할 이유가 있음 |
| 볼륨 | 콘텐츠 종류 | 적 1종, 스테이지 1개 | 적 3종, 스테이지 3개 | 적 4종 이상, 스테이지 5개 이상 + 보스 |
| 학습 | 단어·문제 | 30개 미만, 유형 1개 | 50개, 오답노트 화면 | 50개 이상, 유형 2개 이상, 도감·복습 흐름 |
| 학습 | 배운 게 남는 느낌 | 결과에 아무것도 없음 | 틀린 단어가 결과·오답노트에 | 새로 배운 단어·복습 진행률이 보임 |
| 게임성 | 난이도 곡선 | 처음부터 끝까지 같음 | 뒤로 갈수록 어려워짐 | 봇(dodge 0.7)이 후반에 가끔 지고, dodge 1.0은 클리어 |
| 게임성 | 선택과 성장 | 선택할 것 없음 | 골드로 살 것이 있음 | 장비·포션 선택이 플레이 방식을 바꿈 |
| 게임성 | 손맛 | 프로토타입보다 나빠짐 | 프로토타입과 같음 | 타격감 연출이 더해짐 (CLAUDE.md 손맛 기준값 유지 또는 근거 있는 변경) |
| 그래픽 | 캐릭터·배경 | 기본 도형 | 통일된 로폴리 에셋 | 애니메이션·조명·스테이지별 분위기까지 |
| 그래픽 | UI | 겹치거나 잘림 | 세로 화면에서 깔끔 | 설명 없이도 읽히고, 상태 변화가 눈에 띔 |
| 원칙 | Show, don't tell | 설명문이 많음 | 설명문 최소 | 첫 판을 설명 없이 배움 (스크린샷으로 확인) |
| 품질 | 안정성 | 콘솔 오류 있음 | 오류 0, 테스트 통과 | 여러 판 오류 0, 시간 초과 0, 로딩 빠름 |
| 품질 | 성능 | 오너 PC에서 30fps 미만 | 오너 PC에서 60fps | 에셋 용량·드로우콜까지 관리 |
